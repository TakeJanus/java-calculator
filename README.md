# java-calculator-precourse

## 기능 목록

- [ ] 빈 문자열 또는 null 값을 입력할 경우 0을 반환하고 프로그램을 종료한다.
- [ ] 숫자 하나만 문자열로 입력할 경우 해당 숫자를 반환하고 프로그램을 종료한다.
- [ ] 쉼표(,) 또는 콜론(:)을 구분자로 가지는 문자열을 전달하는 경우 각 숫자의 합을 반환한다.
- [ ] "//"와 "\n" 문자 사이에 커스텀 구분자를 지정할 수 있다.(문자, 기호 등 모두 가능. 제한 글자 수 5)
- [ ] 문자열 계산기에 음수를 전달하는 경우 `IllegalArgumentException`을 발생시키고 프로그램을 종료한다.(오직 덧셈만 기능하게 한다.)
- [ ] 숫자 입력 부분에 문자, 기호 등 잘못된 값을 입력한 경우 `IllegalArgumentException`을 발생시키고 프로그램을 종료한다.
